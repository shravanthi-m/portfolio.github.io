# Shravanthi Murugesan | Portfolio

My personal portfolio website showcasing my projects, research work, and technical interests in AI, robotics, computer vision, and ML.

## Live Demo

Visit the deployed portfolio here:

https://shravanthi-murugesan-portfolio.vercel.app

## Overview

This portfolio is built with React and Vite to present a clean, responsive, and minimal personal brand website. It highlights:

- featured projects
- research and applied ML work
- technical skills and expertise
- links to GitHub and external demos
- a polished dark-mode aesthetic with modern UI styling

## Features

- responsive single-page portfolio layout
- project cards with media previews
- GitHub and external-link integrations
- polished visual design with reusable components
- easy to extend for new projects and sections

## Tech Stack

- React
- Vite
- JavaScript
- CSS
- Lucide icons

## Getting Started

### Prerequisites

- Node.js 18+
- npm

### Installation

```bash
npm install
```

### Run locally

```bash
npm run dev
```

Then open the local URL shown in the terminal, typically:

```bash
http://localhost:5173
```

### Production build

```bash
npm run build
```
